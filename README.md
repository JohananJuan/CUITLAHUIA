## 🌾 Nuestra visión

Cuitlalia es una iniciativa tecnológica enfocada en la agricultura inteligente, que busca integrar visión por computadora, inteligencia artificial y análisis de datos para comprender el desarrollo de los cultivos y mejorar su gestión.

El proyecto comienza con el análisis de plantas de jitomate y busca evolucionar hacia una plataforma adaptable a distintos cultivos, sistemas de producción e invernaderos.
