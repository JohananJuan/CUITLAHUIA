## Sobre el proyecto

CUITLALIA es una iniciativa de desarrollo tecnológico enfocada en la agricultura inteligente. Su propósito es integrar visión por computadora, inteligencia artificial y análisis de datos para obtener información útil sobre el desarrollo de los cultivos.

El proyecto comienza con el análisis visual de plantas de jitomate y busca evolucionar hacia una plataforma adaptable a distintos cultivos, sistemas de producción e invernaderos.

La propuesta combina herramientas de software con las necesidades reales del campo para explorar nuevas formas de observar, analizar y gestionar la producción agrícola.

## Líneas de investigación

- **Detección de plantas y frutos:** localización de elementos de interés en imágenes.
- **Maduración del jitomate:** exploración de características visuales para identificar etapas de maduración.
- **Procesamiento de imágenes:** preparación, transformación y análisis de datos visuales.
- **Aprendizaje automático:** experimentación con modelos de clasificación y detección.
- **Monitoreo ambiental:** integración futura de sensores de temperatura, humedad y otras variables.
- **Gestión agrícola:** organización de observaciones y análisis de información para apoyar decisiones.

## Instalación y ejecución

Los comandos definitivos dependerán de las dependencias y del punto de entrada del proyecto.

Para preparar un entorno virtual de Python en Windows:

```powershell
git clone https://github.com/JohananJuan/CUITLAHUIA.git
cd CUITLAHUIA

python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Si el proyecto ya incluye `requirements.txt`, instala las dependencias con:

```powershell
python -m pip install -r requirements.txt
```

Para ejecutar el sistema, consulta el archivo principal y las instrucciones específicas de la implementación actual.
